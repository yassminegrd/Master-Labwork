About This Project

This system was developed as a software laboratory work for the Apprentissage par Machine 02 (Machine Learning 02) course at the University of Constantine 2 — Abdelhamid Mehri.

The goal is to detect potential signs of dysgraphia — a neurological learning difficulty affecting handwriting — using image processing and machine learning.

Methodology

  1. 1
    Image Preprocessing — Grayscale conversion, Gaussian blur, Otsu thresholding
  2. 2
    Feature Extraction — 12 structural & texture features per image
  3. 3
    Model Training — SVM, Random Forest, KNN on 80% of data
  4. 4
    Evaluation — Accuracy, Precision, Recall, F1, Confusion Matrix on 20%
  5. 5
    Best Model Selection — Deployed based on highest F1-score
